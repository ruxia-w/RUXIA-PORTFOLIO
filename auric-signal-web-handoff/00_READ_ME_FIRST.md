## Project intent

AURIC SIGNAL is a three-week independent concept project exploring an AI-assisted portfolio decision-support experience. It helps a self-directed investor move from noticing a change to understanding evidence, evaluating personal impact, simulating alternatives, and saving a non-executing draft.

## Non-negotiable truth boundaries

- Demonstration app using static sample data.
- No broker, exchange, financial-account, live-market-data, or real-trading connection is claimed.
- Scenario and rebalancing outputs are estimates and simulations only.
- Nothing is executed.
- Nothing in the product or case study is financial advice.
- No documented primary interviews or formal usability study are claimed.
- Do not publish “findings from testing,” participant counts, improved trust, increased confidence, business impact, or model performance as verified outcomes.
- “High confidence” is a conceptual UI state. It is not validated prediction accuracy.
- “Better than 68% of similar investors” is static demonstration copy, not a verified benchmark.

## Build boundary

This is a migration and system upgrade, not a redesign of the existing portfolio content. Preserve existing project assets. Build reusable structure, navigation, responsive behavior, media handling, and accessibility first. Do not choose or replace the global portfolio color or typography system in this phase.
