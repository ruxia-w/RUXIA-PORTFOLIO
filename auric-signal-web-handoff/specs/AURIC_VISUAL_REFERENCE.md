## Asset behavior

- Preserve supplied UI screenshots exactly; do not recolor them.
- Do not add neon glow.
- Use restrained presentation shadows only if the surrounding portfolio system already uses them.
- Do not force phone mockup frames around every screenshot.
- Do not repeat the AURIC logo on every section.
- Do not infer the global site typography from the app UI.

## Process assets

Process boards use a light presentation style. Preserve them as process evidence rather than restyling them to match the dark app.
